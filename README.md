# Hotel Analytics

Аналитический конвейер для годового отчета гостиницы:

1. пользователь выбирает Excel-файл отчета;
2. листы экспортируются в CSV без зависимости от установленного Microsoft Excel;
3. строки гостей извлекаются в нормализованную таблицу;
4. формируется HTML-отчет с графиками, таблицами, модальными окнами и аудитом данных.

## Запуск профилирования

```powershell
python .\run_profile.py
```

Скрипт берет первый Excel-файл из папки `Data/` и сохраняет результаты в `outputs/profile/`.

## Генерация HTML-отчета

```powershell
python .\run_dashboard.py
```

Скрипт берет первый Excel-файл из папки `Data/`. HTML-отчет появится в отдельной папке `reports/<дата_и_время>/report.html`.

## Запуск приложения

```powershell
python .\run_app.py
```

В интерфейсе:

1. выберите Excel-файл;
2. выберите папку для сохранения отчетов или оставьте `reports`;
3. нажмите `Сформировать отчет`;
4. нажмите `Открыть отчет`.

## Сборка Windows-приложения

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

Готовые файлы появятся в `release/`:

- `HotelAnalytics.exe`;
- `README.txt`.

## Возможности отчета

- KPI `Общий доход` открывает топ источников выручки;
- KPI `Повторные гости` открывает топ повторных гостей;
- строки городов открывают топ гостей по выбранному городу;
- KPI `No-show` открывает список no-show бронирований;
- строки в топе гостей открывают краткую карточку гостя;
- блок межлистовой сверки показывает детали расхождений между листами;
- вкладка `Топы` поддерживает сортировку по валютным и числовым показателям.

## Основные артефакты

- `clean_guests.csv` - нормализованные строки гостей;
- `summary.json` / `profile.json` - ключевые KPI и агрегаты;
- `segments.csv` - агрегаты по CLUB-сегментам;
- `cities.csv` - агрегаты по городам;
- `repeat_guests.csv` - агрегаты по количеству заездов;
- `service_spend.csv` - траты по дополнительным услугам;
- `top_guests.csv` - топ гостей по доходу;
- `data_quality.json` - проверки качества данных;
- `audit_report.json` - контракт источников, сверка листов и правила надежности;
- `dashboard_reliability.csv` - статусы надежности блоков дашборда;
- `category_rows.csv` - строки листа `категории номеров`;
- `guest_details.csv` - объединение основного листа с деталями из листа категорий.

## Контракт данных

- `аналитика 2025` - источник истины для финансов, ночей, заездов, городов и CLUB-сегментов.
- `категории номеров` - источник деталей гостя: категории, комментарии, способ бронирования.
- `Дубли` - справочный лист с персональными данными; в публичный дашборд не включается.

Если между листами есть расхождения по финансовым суммам, программа оставляет суммы из листа `аналитика 2025` и показывает детали расхождений в аудите.
